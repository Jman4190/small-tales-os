# Contributing

This project is no longer actively maintained. Forks are welcome; pull requests and issues may not receive a response.

Use Node.js 22.22 or newer. Run `./setup.sh` and follow the README to configure your own development services. Keep changes small enough to review and explain the behavior they improve.

Run relevant tests, `npm run lint`, and `npm run build` before opening a pull request. Add regression coverage for security-sensitive changes. Include reproduction steps, expected/actual results, and checks performed.

Never include real credentials, customer data, uploaded photos, generated customer books, or private recordings in issues, pull requests, fixtures, or screenshots. Use synthetic data and media you may share. Report vulnerabilities privately through [SECURITY.md](SECURITY.md).

Contributions are submitted under the repository's MIT license. Preserve third-party copyright and license notices.
